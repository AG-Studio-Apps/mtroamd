meshtermd · packages

Server-side daemon for the meshTerm iOS app — persistent terminal sessions over QUIC, plus the mtctl CLI. Signed apt + dnf repos for amd64/x86_64, arm64/aarch64 (armhf on apt).

Debian / Ubuntu (apt)

Stablefrom v2.0

Production channel — tracks the App Store app's pinned version. Live when meshTerm 2.0 ships; until then this reports no package.

curl -fsSL https://ag-studio-apps.github.io/meshtermd/meshtermd-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/meshtermd-archive-keyring.gpg > /dev/null

echo "deb [signed-by=/usr/share/keyrings/meshtermd-archive-keyring.gpg] https://ag-studio-apps.github.io/meshtermd stable main" \
  | sudo tee /etc/apt/sources.list.d/meshtermd.list

sudo apt update && sudo apt install meshtermd
systemctl --user enable --now meshtermd   # as your login user

Fedora (dnf)

Stablefrom v2.0

Live when meshTerm 2.0 ships; until then this reports no package.

sudo tee /etc/yum.repos.d/meshtermd.repo <<'EOF'
[meshtermd]
name=meshtermd
baseurl=https://ag-studio-apps.github.io/meshtermd/rpm/stable/$basearch
enabled=1
gpgcheck=1
gpgkey=https://ag-studio-apps.github.io/meshtermd/meshtermd-archive-keyring.asc
EOF

sudo dnf install meshtermd
systemctl --user enable --now meshtermd   # as your login user

Uninstall

# Debian / Ubuntu
sudo apt remove meshtermd     # stops + removes the daemon, keeps your sessions + cert
sudo apt purge  meshtermd     # also wipes ~/.local/share/meshtermd (full clean removal)

# Fedora
sudo dnf remove meshtermd     # stops + removes the daemon, keeps your sessions + cert
