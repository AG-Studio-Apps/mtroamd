meshtermd · apt

Server-side daemon for the meshTerm iOS app — persistent terminal sessions over QUIC, plus the mtctl CLI. Debian / Ubuntu packages for amd64, arm64, armhf.

Stablefrom v2.0

The production channel — tracks the version paired with the live App Store app. It goes live when meshTerm 2.0 ships; until then the commands below will report no package.

curl -fsSL https://ag-studio-apps.github.io/meshtermd/meshtermd-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/meshtermd-archive-keyring.gpg > /dev/null

echo "deb [signed-by=/usr/share/keyrings/meshtermd-archive-keyring.gpg] https://ag-studio-apps.github.io/meshtermd stable main" \
  | sudo tee /etc/apt/sources.list.d/meshtermd.list

sudo apt update && sudo apt install meshtermd

# then, as your login user:
systemctl --user enable --now meshtermd

Developmentlive

⚠ Unstable — may break your system. Pre-release (-rc) builds for testing; pairs with TestFlight, not the App Store app. Not for production. Drop the dev source and apt upgrade to converge back to stable.
curl -fsSL https://ag-studio-apps.github.io/meshtermd/meshtermd-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/meshtermd-archive-keyring.gpg > /dev/null

echo "deb [signed-by=/usr/share/keyrings/meshtermd-archive-keyring.gpg] https://ag-studio-apps.github.io/meshtermd dev main" \
  | sudo tee /etc/apt/sources.list.d/meshtermd-dev.list

sudo apt update && sudo apt install meshtermd

# then, as your login user:
systemctl --user enable --now meshtermd

Uninstall

sudo apt remove meshtermd     # stops + removes the daemon, keeps your sessions + cert
sudo apt purge  meshtermd     # also wipes ~/.local/share/meshtermd (full clean removal)
